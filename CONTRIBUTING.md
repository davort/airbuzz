# Contributing to AirBuzz

Issues and feedback are very welcome. If something didn't buzz, buzzed when it shouldn't have, or is confusing, please [open an issue](https://github.com/davort/airbuzz/issues).

AirBuzz is a small project by Misek AB. Before you write code, please open an issue so we can agree on the change first. Pull requests that weren't discussed first may be closed.

Contributions are accepted under the GPL-3.0 with the additional terms in `NOTICE.md`, the licence of the rest of AirBuzz (see `LICENSE`). If you add code or assets from somewhere else, list them in `THIRD_PARTY_NOTICES.md` with their licence.

## Keep personal data out of issues

Issues are public. Don't put names, phone numbers, message text or other personal details in them.

AirBuzz's log (Settings → Share log) can help us find a problem, but don't paste it into an issue. Email it to support@airbuzz.me instead, and say which issue it belongs to.
